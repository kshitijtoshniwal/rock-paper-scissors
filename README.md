# Rock Paper Scissors

A browser-based Rock Paper Scissors game built with HTML, CSS, and JavaScript.

## Features

- Play by selecting Rock, Paper, or Scissors.
- Random computer moves.
- Score tracking.
- The first player to reach 5 points wins.
- Results displayed on the page.

## Run locally

Clone the repository, then open `index.html` in your browser.

## Built with

- HTML
- CSS
- JavaScript
